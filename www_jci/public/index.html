Minimal. Offline. Local.

Jaypore CI is a minimal single-binary CI system, that can run offline on your own laptop.

It supports complex workflows, has a web interface, and has collaboration via git.

Binaries

Download binaries

Download a binary of your choice and move it to /usr/bin/git-jci. Git will automatically start picking up the command and you can start running as git jci web.

Documentation

README.md for docs

Go through the README.md file to see how things work. A simple workflow is:

  • git jci run executes your pipeline. Run this mannually, or via pre-commit, or cron as shown below.
  • git jci web runs a web server, browse the CI results locally.
  • git jci push/pull syncs refs with your remotes.
  • git jci cron sync syncs your cron spec with system cron so that you can run midnight builds for example.
